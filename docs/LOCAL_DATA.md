# Локальные данные beta

Цель сохранения — продолжить разбор после закрытия приложения и не показывать повторно неизменившиеся оставленные файлы. Приложение работает с одной выбранной папкой; серверов и сторонних получателей нет.

| Данные | Источник и назначение | Хранение и удаление |
| --- | --- | --- |
| Security-scoped bookmark | Системный выбор папки; восстановление разрешённого доступа | Контейнер приложения, `Unpile/folder.bookmark`; удаляется при отключении папки |
| Идентичность папки, имя файла, device/inode/size/mtime, UUID, решение и история Undo | Свежий список обычных файлов; сверка версии и восстановление очереди | `Unpile/review-state.json`; атомарная запись после решения, каталог 0700 / файл 0600 |
| Порядок, включение недавних, размер сессии | Выбор пользователя | В том же файле состояния |
| Код языка system/en/ru | Выбор пользователя; язык интерфейса | Один scalar в UserDefaults контейнера; до изменения выбора или удаления данных приложения |
| Имена и состояние незавершённого переноса | Подтверждённая операция; предотвращение автоматического повторения | Отдельный журнал 0600; удаляется после завершения или ручной проверки |
| Превью/миниатюра | Локальный Quick Look / Quick Look Thumbnailing | Приложение держит миниатюру в памяти, закрывает полный просмотр после sheet; системным кешем Quick Look управляет macOS |

В состоянии разбора нет абсолютных путей, содержимого файлов, миниатюр, токенов или аналитики. Имена файлов могут быть личными данными: их не выводим в логи, публичные материалы или тестовые отчёты. JSON не является зашифрованным хранилищем; доступ ограничен sandbox и правами текущего пользователя, защита диска зависит от настроек macOS/FileVault.

Решения сохраняются до изменения/исчезновения файла, отключения папки, выбора другой папки или явного сброса сохранённого разбора. Сверка происходит после сканирования. «Позже» действует до нового разбора; «Оставить» пропускается в следующих сессиях до пересмотра. Кандидаты восстанавливаются для проверки, но никогда не переносятся автоматически.

Из сохранённых имён не конструируются адреса для переноса: восстановление допускает только совпадение со свежими записями разрешённой папки. Другая папка, заменённый файл, ссылка, неподдерживаемая схема, повторяющиеся идентификаторы или некорректный JSON не получают старых решений. Неудачная запись не принимается молча: новое решение откатывается, перенос блокируется, интерфейс предлагает повтор записи или явный сброс локальной памяти.

Временные файлы атомарной записи имеют имена `.review-UUID.tmp` и права 0600. При нормальном завершении они исчезают; остатки аварийной записи удаляются при следующем запуске или явном сбросе. Очистка не следует ссылкам и не удаляет каталоги рекурсивно.

QA использует отдельную идентичность приложения и исключительно синтетические папки. Ни содержимое пользовательских Downloads, ни их локальное состояние не нужны для проверки.
