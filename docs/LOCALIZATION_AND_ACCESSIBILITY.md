# Локализация, доступность и просмотр

Beta 0.7.0; gesture behavior and UI are unchanged from 0.6.0.

## Языки

В настройках доступны «Как в системе», English и Русский. Переключение действует сразу и не пересоздаёт очередь. Выбор хранится как один код языка в UserDefaults контейнера приложения; решения папки хранятся отдельно. При неподдерживаемом системном языке используется английский.

Два `Localizable.strings` в ресурсах UnpileCore содержат интерфейс, ошибки, подтверждения, результаты и accessibility descriptions. Сообщения модели хранят ключ и числовые аргументы, поэтому уже существующие статусы переводятся при смене языка. Даты, размеры и числа используют выбранную locale; формы количества файлов покрывают оба поддерживаемых языка.

В текущем CLI toolchain применены обычные `.strings` вместо требующего отдельной обработки String Catalog. Ресурсы объявлены в Swift Package через `defaultLocalization` и `.process`, как описано в [документации Apple](https://developer.apple.com/documentation/xcode/localizing-package-resources). Скрипт упаковки копирует bundle в Contents/Resources; приложение сначала ищет его в собственной поставке. Это позволяет запускать `.app` вне каталога сборки. Release не использует абсолютный путь resource bundle из рабочего каталога; локальная распространяемая сборка не включает debug info.

Нативные системные меню, диалог выбора папки и внутренние controls Quick Look используют язык macOS. Их приложение не подменяет.

## Доступность и клавиатура

- Заголовки, названия действий и подсказки для оставления/откладывания/кандидата.
- Метаданные текущего файла читаются вместе: полное имя, размер, явно обозначенная дата изменения. Декоративные изображения скрыты от чтения экрана.
- Очередь содержит описания следующего файла, прогресс — количество просмотренных. При новой карточке запрашивается VoiceOver focus на метаданные.
- ← / → / ↓, Space, Cmd+Z, Cmd+Enter, Cmd+O, Cmd+, и Escape. Tab-навигация стандартных controls следует настройке Keyboard Navigation macOS.
- Во время превью, настроек, выбора папки, подтверждения и ошибки команды не меняют скрытые решения. Выполнение переноса остаётся отдельным действием.
- Reduce Motion и Reduce Transparency сохранены.
- Двухпальцевые свайпы дополняют кнопки и клавиатуру. Панель решений закреплена вне прокрутки, декоративные иконки/стрелки скрыты из accessibility labels. Подробности — [GESTURES_AND_DESIGN.md](GESTURES_AND_DESIGN.md).

Локальный QA проверяет accessibility tree, подписи и блокировку команд в модальных состояниях. Полный проход с включённой речью VoiceOver и пользовательский пилот ещё нужны перед публичной v1; результат проверки дерева не выдаётся за проверку озвучивания.

## Полноценный просмотр

Карточка использует миниатюру. Space/кнопка просмотра открывает системный [QLPreviewView](https://developer.apple.com/documentation/quicklookui/qlpreviewview) в отдельном sheet. PDF содержит доступный текст и несколько страниц; изображение можно рассмотреть крупно. Для media установлен `autostarts = false`. При закрытии view освобождает preview item.

Перед открытием повторно сверяется версия; allowlist остаётся image/PDF/movie/audio с исключением HTML/SVG. Демонстрация использует вымышленные превью. Изменённый или недоступный файл получает сообщение; дополнительного переноса нет.

QA использует отдельный bundle ID, PNG, трёхстраничный PDF и пять секунд синтетической тишины WAV. Чтение файлов через Quick Look остаётся локальным; системным кешем управляет macOS.
