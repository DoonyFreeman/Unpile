# UI / UX specification

Концепция 0.1 · 9 октября 2026. Это спецификация будущего приложения; интерактивный макет использует только вымышленные файлы и не работает с диском.

## 1. Дизайн-принципы

- Один файл и одно решение в центре внимания.
- Превью занимает больше места, чем декоративная анимация.
- Названия действий описывают результат: «На удаление», «Оставить», «Позже».
- Системные элементы и привычки macOS: меню, Quick Look на пробел, Cmd+Z, sheet для подтверждения.
- Безопасность выражена устройством сценария: отметить → проверить → подтвердить → Корзина.
- Объём выбранных файлов виден, но не подталкивает удалять ценное ради счётчика.
- Пользователь может закончить после любого количества решений.

## 2. Визуальное направление

Современная нативная утилита в духе macOS 27 / Liquid Glass: системный шрифт SF, мягкие материалы в панели управления и кнопках, тонкие блики, выразительные скругления и аккуратные тени. Карточка файла — главный предмет интерфейса, с большим превью, чистой типографикой и ощущением стопки. Один основной акцент, естественная светлая/тёмная тема. Красный используется для кандидатов на удаление и ошибок, смысл всегда продублирован текстом.

Опора — [официальные design kits Apple для macOS 27](https://developer.apple.com/news/?id=e2lxw9l1). Это направление оформления, а не требование macOS 27 для запуска: на старых поддерживаемых системах использовать доступные нативные материалы. Не имитировать все оптические эффекты Liquid Glass вручную в production. Учитывать Reduce Transparency и контраст: содержимое файла и важные подписи остаются читаемыми.

Рекомендуемый начальный размер окна около 920 × 680 pt, минимальный ориентир 720 × 560 pt. Точные ограничения выбрать после проверки масштабирования текста. При уменьшении окна перестраивать компоненты, сохранять все действия и полный доступ к имени файла. В обсуждаемом макете маленькие экраны показывают адаптацию компоновки, а не обещание мобильного приложения.

Без постоянного sidebar для одной папки, огромных декоративных иконок, карточек статистики «здоровье Mac» и статусных кругов. Не копировать оформление Tinder. Анимация короткая, одноразовая; Reduce Motion заменяет перемещение простым изменением состояния.

Два направления для исследования:

| Направление | Компоновка | Плюс | Что проверить |
| --- | --- | --- | --- |
| Фокус | Большая центральная карточка, метаданные под ней, действия снизу | Минимум отвлечений, простое первое использование | Не теряет ли пользователь контекст очереди |
| Обзор | Компактнее карточка; справа несколько следующих элементов | Видно, что будет дальше; удобно для повторного использования | Не превращается ли разбор обратно в длинный список |

Пользователь выбрал «Обзор» как основное направление; развивать его с более выразительными кнопками и карточкой. «Фокус» остаётся альтернативой для сравнения. Полный список нужен на этапе проверки; несколько разных режимов разбора не являются обязательством первой версии.

## 3. Структура экранов

**Welcome → Выбор папки → Подготовка сессии → Разбор ↔ Просмотр файла → Проверка → Выполнение → Итог.**

Настройки и «Повторно показать оставленные» доступны через меню приложения и компактную кнопку, без отдельной большой панели управления.

### Welcome и доступ

Заголовок: «Разберите Загрузки по одному файлу».

Текст: «Смотрите превью и решайте, что оставить. Файлы отправятся в Корзину только после вашей проверки».

Главное действие: «Выбрать папку Загрузки…», открывающее NSOpenPanel с предложенной Downloads. В v1.0 поддерживается одна выбранная локальная папка; при другой допустимой папке интерфейс показывает её фактическое имя. Системные каталоги и неподдерживаемые тома отклоняются с понятной причиной.

Короткое объяснение доступа: «Нужен доступ к выбранной папке, чтобы показать файлы и по вашему подтверждению перемещать их в Корзину». Не использовать «мы всё видим» и не требовать Full Disk Access.

При отмене диалога остаётся Welcome. При ошибке доступа — причина и «Выбрать папку снова». Не устраивать цикл системных запросов.

### Подготовка

- Имя выбранной папки и открытие её в Finder.
- Количество подходящих файлов, суммарный логический размер, количество исключений.
- Сортировка: «Крупные сначала» по умолчанию; «Старые сначала» по дате изменения; «По имени».
- Объём сессии: «До 20 файлов» по умолчанию; «Все».
- «Включить недавние файлы» по умолчанию выключено; рядом понятно указано «Изменённые за последние 24 часа».
- Основная кнопка: «Начать разбор»; если подходящих меньше 20, показывать фактическое число.

Полную очередь строить по метаданным; не ждать всех миниатюр. Пока идёт сканирование — видимое состояние «Читаем список файлов…», затем реальные данные. Не показывать придуманный процент.

### Разбор

Верхняя строка: фактическая папка, активная сортировка, прогресс «7 из 20», «Завершить».

Карточка:

- Превью с корректными пропорциями. Для изображения — вписанная миниатюра; PDF — первая страница; видео — неподвижный кадр с длительностью, если доступна; архив/установщик — тип и метаданные без открытия содержимого.
- Полное имя, допускающее перенос строк. Для длинного имени есть копирование/просмотр полного значения.
- Размер в локализованном формате, тип, дата изменения. Относительный путь нужен только при неоднозначности; полный путь не публикуется в примерах.
- Действия «Быстрый просмотр» и «Показать в Finder». Открытие в приложении по умолчанию — отдельная осознанная команда меню, без автозапуска.
- При ошибке миниатюры — обычная карточка метаданных, кнопки выбора работают.

Нижняя строка: «На удаление», «Позже», «Оставить». Под ней компактные «Отменить» и «Проверить выбранное · N · объём».

При первом выборе «На удаление» краткий статус: «Добавлено к проверке». Не открывать подтверждение на каждый файл. После первого объяснения постоянная краткая подпись: «Перенос в Корзину — после проверки».

### Быстрый просмотр

Пробел открывает системный Quick Look допустимого файла; Escape закрывает. Пока просмотр открыт, стрелки не должны параллельно принимать решения. Файл нельзя автоматически запускать при выборе карточки или генерации превью.

HTML/SVG и исполняемые файлы в MVP ограничиваются карточкой метаданных; нельзя встраивать произвольное активное содержимое в WebView. Поддержку форматов и поведение Quick Look проверять в подписанной sandbox-сборке.

### Проверка кандидатов

Sheet или отдельный экран: «Проверить перед переносом в Корзину».

Список: миниатюра/тип, имя, размер, дата; каждый файл можно исключить через «Оставить». Для 1 000 кандидатов использовать эффективный прокручиваемый список, а не тысячи тяжёлых превью.

Итог: «N файлов · X ГБ выбрано для Корзины». Пояснение: «Они останутся на диске до очистки Корзины».

Кнопки: «Вернуться к разбору» и «Переместить N файлов в Корзину». Финальная операция не привязана к обычному Enter: Enter и Cmd+Enter не должны случайно подтвердить перенос. Первоначальный фокус — нейтральное действие; доступна явная клавиатурная навигация к подтверждению.

Повторно проверить состояние файлов. Изменённые кандидаты исключить из выполнения и показать «Файл изменился после просмотра. Проверьте его снова». При нулевом количестве допустимых файлов кнопка выполнения отключена.

### Выполнение и итог

Во время работы — «Перемещено 3 из 8». Повторное подтверждение заблокировано. «Остановить» останавливает последующие операции; завершившиеся не откатываются автоматически. Закрытие окна не обрывает без объяснения текущую файловую операцию.

Итог успешной пачки: «8 файлов перемещено в Корзину · 2,4 ГБ». Действия: «Открыть Корзину», «Продолжить разбор», «Готово».

Пояснение: «Чтобы вернуть место, очистите Корзину в Finder, когда будете уверены. После её очистки восстановление через Корзину недоступно». Приложение само её не очищает.

При частичных ошибках: «6 перемещено, 2 пропущено». Поэлементные причины и действия «Проверить снова»/«Показать в Finder». «Повторить» заново проверяет объект и не повторяет автоматически всё старое намерение.

Если кандидатов нет: «Разбор завершён. Все файлы остались на месте». При досрочном завершении показывать реальное число просмотренных, без оценки пользователя.

## 4. Жесты и клавиатура

| Ввод | Действие |
| --- | --- |
| Перетаскивание карточки влево | Отметить «На удаление» |
| Перетаскивание вправо | Оставить |
| Малое/вертикальное перетаскивание | Вернуть карточку без решения |
| Стрелка влево / вправо | Отметить / оставить, только при фокусе на разборе |
| Стрелка вниз | Позже, только при фокусе на разборе; есть видимая кнопка |
| Space | Quick Look |
| Cmd+Z | Отменить решение до переноса |
| Cmd+Enter | Открыть проверку, без выполнения переноса |
| Escape | Закрыть Quick Look/sheet или отменить жест |

Мобильная метафора на Mac — это дополнение. Главный быстрый путь для повторного использования — клавиатура. Физический двухпальцевый swipe трекпада не приравнивать автоматически к SwiftUI DragGesture: начать с drag карточки и проверить нативные события отдельно. Не перехватывать обычный scroll и Back/Forward.

Порог жеста — ориентир 25% ширины карточки с явным текстом направления; подтвердить в пилоте. Решение регистрировать при отпускании. Быстрый повтор клавиши/инерция жеста не должны обработать несколько следующих файлов случайно.

## 5. Состояния и пограничные ситуации

| Состояние | Что видит пользователь | Действие |
| --- | --- | --- |
| Пустая папка | «Здесь пока нечего разбирать» | Выбрать папку/закрыть |
| Всё уже оставлено | «Новых файлов нет» | «Пересмотреть оставленные» |
| Всё слишком новое/исключено | Количество и причины исключений | Включить недавние или открыть Finder |
| Отозван доступ | «Доступ к папке больше недоступен» | Выбрать её снова |
| Файл исчез | «Файл перемещён или удалён другой программой» | Следующая карточка |
| Файл изменился | Не считается старым кандидатом | Повторный просмотр |
| Превью грузится/сломалось | Метаданные остаются видимыми | Решение доступно, возможен просмотр в Finder |
| Перенос запрещён | Поэлементная причина, файл считается оставшимся | Исправить доступ, проверить снова |
| Новые файлы во время сессии | Не вставлять их внезапно под текущий свайп | Обновить следующую сессию |
| Закрытие до подтверждения | «Продолжить позже» или «Отменить разбор» | Никакого автоматического переноса |
| Сбой во время пачки | «Проверяем состояние предыдущего переноса» | Сверка перед любыми новыми операциями |

## 6. Доступность, язык и проверка

Все действия доступны без жестов и различения цветов. VoiceOver читает имя, тип, размер, дату и доступные команды; новые карточки объявляются один раз. Чёткие фокусные состояния, системная навигация Tab, достаточные контрасты, нет потери функций при Reduce Motion.

Числа, даты, множественное число и кнопки локализуются через локализованные ресурсы (в CLI beta — .strings). Английский — язык основного README, русский перевод — отдельный документ. Избегать строки «Last opened», если достоверные метаданные отсутствуют; не выдавать дату изменения за дату загрузки.

QA: обычное и минимальное окно, 1×/2× экран, светлая/тёмная тема, длинные кириллические/Unicode имена, 100%/увеличенный текст, только клавиатура, VoiceOver, Reduce Motion, пустая очередь, недоступное превью, частичная ошибка и восстановление после закрытия.

## 7. Что проверено на этапе концепции

9 октября 2026 интерактивный макет проверен в браузере: оба направления, широкая и узкая компоновка, светлое/тёмное отображение, три решения, отмена, клавиатурные команды, демонстрационный просмотр, проверка списка, исключение кандидата, итог и продолжение. Проверено отсутствие горизонтального переполнения на узком экране; ошибок JavaScript в наблюдаемом журнале нет.

Это проверка обсуждаемого макета на синтетических данных. Нативное приложение, реальные файловые операции, sandbox, подпись, VoiceOver и производительность пока не проверялись и остаются задачами реализации.

После выбора «Обзор» обновлён визуальный вариант в духе Liquid Glass: объёмная стопка карточек, выразительное превью, округлые кнопки с бликами, мягкая панель следующих файлов и компактный нижний блок действий. В обновлённом макете повторно проверены оба направления, широкая/узкая компоновка, выбор/отмена, просмотр, исключение кандидата и завершение без переноса; ошибок JavaScript в наблюдаемом журнале нет. Проверка нативных материалов и системной доступности остаётся этапом реализации.


10 октября 2026: в нативной beta 0.3 добавлены настройки сессии 20/50/100, локальное продолжение с Undo, сохранённые кандидаты и пересмотр оставленных. Проверены перезапуск, новая очередь, изменение версии файла, отказ записи и явный сброс повреждённого состояния. Для «Позже» используется стрелка вниз, чтобы команда не зависела от раскладки. Английская локализация и полный VoiceOver-проход остаются следующим этапом.

10 октября 2026: beta 0.4 добавляет English/Русский, live-переключение без сброса сессии, локализованные сообщения/метаданные, описания accessibility и полноценный системный Quick Look. Проверены интерфейс и keyboard guards; полный проход с озвучиванием VoiceOver остаётся проверкой перед v1.
