# Прогресс разработки

[Публичная beta 0.7.0](https://github.com/DoonyFreeman/Unpile/releases/tag/v0.7.0-beta.1) опубликована 11 октября 2026 после одобрения конкретной ревизии и назначения.

## Завершено локально

### Этап 1: нативный прототип и безопасное чтение

- SwiftUI/AppKit, нативные Liquid Glass controls с fallback, карточка файла с превью высотой 280 pt.
- Выбор папки через NSOpenPanel, security-scoped bookmark и восстановление доступа после повторного запуска.
- Асинхронное чтение обычных файлов верхнего уровня, фильтрация ссылок/пакетов/скрытых/незавершённых/iCloud-элементов и недавних файлов.
- Сортировка, сессия до 20 файлов, три решения, Undo, клавиши и drag карточки.
- Миниатюры безопасных типов через Quick Look Thumbnailing; активные HTML/SVG не просматриваются.
- Проверка списка и исключение кандидатов. Первая сборка 0.1 была ограничена чтением.

### Этап 2: перенос в Корзину

- Отдельное подтверждение списка, без привязки финального переноса к обычному Enter/Cmd+Enter.
- Повторная проверка типа, устройства, inode, размера, времени изменения и родительской папки.
- Проверка внутри NSFileCoordinator перед `FileManager.trashItem`; permanent-delete fallback отсутствует.
- Последовательные операции, остановка следующих действий, поэлементные результаты.
- Атомарный локальный журнал с синхронизацией перед каждой операцией. Права каталога 0700, файлов 0600.
- Незавершённое/нечитаемое состояние блокирует новый перенос до ручной проверки; автоматического повторения нет.
- Успешные файлы исключаются из очереди и decision-only Undo.
- Сборки имеют отдельные пути; открытый прототип 0.1 не перезаписывается.

### Этап 3а: продолжение разбора и настройки

- Сохраняются очередь, решения, история Undo и параметры выбранной папки; схема JSON версионирована.
- Восстановление использует только свежий Inventory. Файл с изменёнными метаданными получает новый UUID и требует нового решения; ссылки и другая папка не наследуют намерения.
- «Оставить» сохраняется между разборами, «Позже» возвращается в новой сессии; можно пересмотреть оставленные.
- Размер сессии 20/50/100, сортировка и недавние файлы — в настройках, доступных через кнопку и Cmd+,.
- Кандидаты восстанавливаются для отдельной проверки. Перенос после запуска автоматически не выполняется.
- Запись: временный файл 0600, синхронизация, атомарный rename после успешной записи. Отказ не заменяет принятые решения; интерфейс блокирует перенос и предлагает повторить сохранение.
- Остатки аварийной записи очищаются при запуске/сбросе; посторонние файлы сохраняются.
- Повреждённое/неподдерживаемое состояние не перезаписывается молча; есть явный сброс только памяти приложения.
- Отключение/смена папки очищает связанные решения; демо не меняет сохранённый реальный разбор.
- Карта локальных данных и сроков хранения — [LOCAL_DATA.md](LOCAL_DATA.md).

### Этап 3б: языки, доступность и Quick Look

- 162 строковых ключа English/Русский: интерфейс, ошибки, подтверждения, результаты и accessibility descriptions.
- Язык system/en/ru переключается сразу и сохраняется отдельно от сессии. Существующие сообщения хранят ключ и аргументы, а не уже переведённую строку.
- Формы количества файлов, числа, даты, размеры и типы используют выбранный язык.
- Заголовки, описания прогресса, полные метаданные текущего/следующего файла, подсказки решений, скрытие декоративных иконок и запрос VoiceOver focus при смене карточки.
- Во время превью, настроек, выбора папки, подтверждения и ошибки блокируются команды скрытого разбора.
- Native QLPreviewView для изображения, PDF и media; autostarts=false, освобождение preview item при закрытии. Демонстрация остаётся синтетической.
- Ресурсный bundle упакован в .app. Подготовлен основной README на английском и отдельный русский.
- Подробнее: [LOCALIZATION_AND_ACCESSIBILITY.md](LOCALIZATION_AND_ACCESSIBILITY.md).

### Этап 4а: локальный release candidate

- Оригинальная иконка, согласованная с branding внутри приложения; все iconset размеры и .icns создаются локальным CoreGraphics-скриптом.
- Universal arm64/x86_64 через раздельную сборку и lipo; Xcode и платное membership не требуются.
- DMG с приложением, Applications symlink, инструкцией, фоном и Finder layout. Только hash-pinned packaging-tools; runtime dependencies не добавлены.
- Верификация signature/sandbox/architectures/icon/resources/data boundaries.
- SHA-256 и source manifest с относительными путями; source tree digest вместо выдуманной commit revision.
- README, CONTRIBUTING, SECURITY, CODE_OF_CONDUCT, CHANGELOG, issue/PR templates, MIT license и workflows подготовлены локально.
- На этом этапе CI и пакет подготовлены локально. Результаты последующей публикации и hosted checks — ниже и в [RELEASE_CANDIDATE.md](RELEASE_CANDIDATE.md).

### Этап 4б: тачпад и обновлённый экран

- Горизонтальные phased precise scroll gestures над видимой карточкой: влево — кандидат, вправо — Keep; решение только при отпускании.
- Axis lock, порог, отмена/реверс, momentum guard, нормализация Natural Scrolling, отключение под overlays и повторная проверка текущего file ID.
- AppKit monitor только для своего окна, без глобального наблюдения и новых permissions; transient input остаётся в RAM.
- Стопка карточек, цветные метки/обводка жеста, spring return и фиксированная панель решений, видимая в компактном окне.
- Пять новых regression checks; все 27 debug checks проходят. Физическая проверка двумя пальцами отделена от автоматических потоков событий.
- Подробнее — [GESTURES_AND_DESIGN.md](GESTURES_AND_DESIGN.md).

## Текущие ограничения

Решения выбранной папки, журнал файловых операций и доступ к папке сохраняются раздельно. Демо остаётся в RAM. Языки интерфейса English/Русский; внутренние системные controls следуют языку macOS. Восстановление — через Finder. FileManager/NSFileCoordinator не дают абсолютной гарантии против гонки с некооперирующим процессом между проверкой и path-based операцией; метаданные не являются криптографическим подтверждением содержимого. Автоматической очистки Корзины, серверов, аккаунтов и встроенной аналитики нет.

Beta 0.7 использует постоянный bundle identifier `io.github.doonyfreeman.unpile`; QA — `io.github.doonyfreeman.unpile.qa`. Временные ID предыдущих beta сохраняются в их старых приложениях.

Из временных beta 0.2–0.6 в 0.7 нет автоматической миграции контейнера. Постоянный ID нужен для следующих версий; совместимость ad hoc обновлений ещё не подтверждена.
