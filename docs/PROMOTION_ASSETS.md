## Что показано

Реальная копия приложения 0.7.0 из проверенного DMG. Скриншоты сделаны через `cua_repl`, только внутри synthetic demo. Mark и Keep выполнены перетаскиванием карточки, Later и Undo — кнопками; список открыт отдельно, затем один кандидат исключён. Пользовательские папки не выбирались, файлы не перемещались. После съёмки восстановлен системный язык и чистое демо.

GIF/MP4 — последовательность семи снятых состояний, а не непрерывная запись интерфейса или физических двухпальцевых жестов. Монтаж: 3 + 3 + 3 + 2 + 2 + 4 + 3 секунды. Подписи показывают следующий результат каждого действия. Числа и имена относятся к вымышленным файлам; освобождение диска не заявляется.

Обработка: цветовой профиль приведён к sRGB; из основных окон убрана верхняя 64 px полоса macOS capture chrome, затем изменён размер. Для обложки/ролика добавлены фон, скругление внешнего снимка и подписи. Содержимое приложения, controls и числовые значения не ретушировались. PNG пересохранены без исходных metadata; шрифтовые файлы не распространяются. Обложка использует оригинальную иконку проекта.

README показывает статичную обложку. GIF открывается только по ссылке; скриншоты доступны без анимации. Alt text описывает содержимое изображений. Beta status, установка, нотарификация и ограничения устройств остаются видимыми рядом со скачиванием и в отдельной секции проверки.

## Локальная проверка пакета

- English/Русский README отрендерены через GitHub Markdown API и осмотрены с локальным стилем на широком и узком экране. Картинки загружаются, галерея раскрывается; горизонтального переполнения нет. Это локальный preview, не снимок уже обновлённого GitHub.
- Все PNG успешно декодируются и не содержат исходных metadata/EXIF; обложка имеет размер 1280 × 640 и меньше 1 МБ.
- GIF: 7 кадров, суммарно 20 секунд; MP4: H.264, 1080 × 960, 20 секунд, без аудио. Полное декодирование и воспроизведение в браузере проверены, media/console errors не обнаружены.
- Локальные ссылки проверены. В публичных assets нет абсолютных путей рабочего или домашнего каталога.
- Sources, Tests, Resources и scripts совпадают с опубликованной ревизией; SHA-256 DMG прежний. Повторная компиляция приложения для изменения документации и изображений не требуется.

Пакет не включает публикацию постов, писем, рекламы, отзывы или цифры популярности. Полная проверка физических жестов, VoiceOver, старых устройств и первого браузерного скачивания остаётся в [прогрессе](PROGRESS.md).
